# _template

Projects are scaffolded by `~/.config/opencode/scripts/new-project.sh` (via the `/new` command),
not by copying this folder. This folder only documents the shape.

Project shape:
- BRIEF.md       - human: goal, why, done when life
- AGENTS.md      - project-only rules (stack, commands, conventions, gotchas)
- opencode.json  - project-only config overrides
- SCOPE.md       - scoper output: IN / OUT / LATER / CUT LINE / RISK
- PLAN.md        - architect output: steps, files, done-when, acceptance
- RESEARCH/      - cited markdown dumps
- REVIEW.md      - reviewer output
- BLIND.md       - critic output (blind spots)
- NOTES.md       - running log
- LEARNINGS.md   - what this project taught the brain
