# 050-mini-project

Anatomy (mini-projects/<slug>/):
- AGENTS.md - project rules (stack, commands, conventions)
- BRIEF.md - human-written: goal, why, done-when-life
- SCOPE.md - scoper output: IN/OUT/LATER/CUT LINE
- PLAN.md - architect output: steps, files, done-when, acceptance
- RESEARCH/ - cited md dumps
- REVIEW.md - reviewer findings
- BLIND.md - critic blind spots
- NOTES.md - running log + decisions
- LEARNINGS.md - what this project taught the brain
- src/code - actual code

Each mini project = its own git repo. Brain repo separate.
